关于本站

「花粥独立资料站」是一个由歌迷维护的非官方资料站。它想做的事很简单：把关于花粥的公开信息整理成能查、能引用、能追溯来源的形式，而不是再做一个应援页面。

这个站是什么

01

本站收录四类内容：人物档案与时间线、作品数据库（66 张专辑与单曲、198 首曲目）、四篇原创音乐专题、以及 34 条已结束的演出记录。这些内容都以静态页面生成，不依赖登录，也不加载追踪脚本。

它不是官方站点。本站与花粥本人、经纪公司 S.A.G、网易云音乐或任何平台都没有隶属关系，也不代表他们的立场。所有推测性内容都会被明确标注为推测。

资料标准

02

  1. 先来源，后叙述

    每一条时间线、专辑、演出记录都附来源链接与访问日期。争议类内容只写「有媒体报道称」「当事人回应称」，不作法律或道德定性。

  2. 查不到就留白

    无法确认的信息会登记在来源与核实页，而不是用「据传」「疑似」含糊带过，更不会编造发行时间、曲目或账号。

  3. 区分事实与观点

    作品数据库与人物档案是事实整理；音乐专题里的分析属于本站判断，会在文章开头说明。

  4. 不搬运受版权保护的内容

    不提供音频下载、不转载完整歌词、不使用艺人照片或官方视觉素材。专辑封面是本站在页面里用排版生成的示意图，不是官方封面。

更新方式

03

作品数据来自网易云音乐公开接口，用仓库里的脚本抓取后生成静态数据文件；人物、演出与争议信息依靠人工查阅公开报道补充。首批资料的核实日期是 2026-11-04。新作品发布后需要重新运行抓取脚本并核对差异，具体步骤写在仓库的 README 里。

当前数据规模：时间线 30 条、专辑与单曲 66 条、曲目 198 首、演出 34 条。
